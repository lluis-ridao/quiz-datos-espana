# ¿Cuánto sabes de España en datos?

Un quiz de diez preguntas sobre España con cifras oficiales: paro, natalidad, inflación, pensiones, sanidad, gasto público… Cada respuesta explica el dato y enlaza su fuente.

**[Jugar ahora](https://lluis-ridao.github.io/quiz-datos-espana/)**

- Las preguntas se cargan en directo desde la API abierta de [DatosClaros](https://www.datosclaros.es), así que se actualizan solas. Si la API no responde, usa una copia guardada en el propio archivo.
- Preguntas y respuestas se barajan en cada partida.
- Un solo archivo HTML, sin anuncios ni rastreadores.
